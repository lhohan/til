# Opencode Web Access Lan Access

On MacOS, access all your Opencode sessions, or start new ones, using Opencode web:

```bash
OPENCODE_SERVER_PASSWORD='your_password' opencode web --mdns --port 4096
```

From your phone or another machine, access using:

- `http://opencode.local:4096`.
- username = `opencode`
- password = `your_password`

Needless to say: change your password to something else. If your network is secure you can skip the password.
